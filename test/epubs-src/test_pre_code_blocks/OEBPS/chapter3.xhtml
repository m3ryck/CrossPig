CSS White Space Modes

PASS when each paragraph follows the white-space rule named in its heading.

Normal

Normal mode collapses runs of spaces and turns newlines into ordinary word boundaries.

Pre Wrap

Pre-wrap keeps runs of spaces. This line starts with four spaces. There is one blank line above this line. Tabs expand into visible spacing.

Pre Line

Pre-line collapses space runs but keeps this line break and the next blank line. This line follows the preserved blank line.

Nested Code

A pre-wrap paragraph can include inline_code() without losing indentation on the following line.
